# Interdisciplinary

**Scope.** Work that does not sit inside one domain: a method from one field
applied to another, a question that needs two literatures, or a result whose
main value is that people will find it remarkable.

Put a project here only when no single domain is its natural home. If one
domain clearly owns the verification standard (a proof, a re-analysis of survey
data), file it there and cross-link.

## How results are verified here

A project inherits the verification standard of every domain it touches. Name
those domains in the project README and follow each of their READMEs.

## Seed directions

- Transfer of a technique between fields that rarely talk (statistical
  physics and social science, phylogenetics and manuscript traditions,
  coding theory and genomics)
- Literature-based discovery: explicit, testable hypotheses formed by joining
  findings from literatures that do not cite each other
- Mathematics of music, art, games, and puzzles, held to the Mathematics
  standard
- Correct, well-sourced, well-visualized answers to questions people are
  curious about and nobody has worked out properly

## Projects

Projects live in [`projects/`](projects/). Create one with
`python scripts/new_project.py interdisciplinary <project-slug>`.
