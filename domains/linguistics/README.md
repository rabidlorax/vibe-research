# Linguistics

**Scope.** Computational, historical, and corpus linguistics, typology, phonology, syntax, semantics, and formal language theory.

**Why this is tractable without a lab.** Language models have read more text in more languages than any person. Corpora and typological databases are open, and formal linguistics is mathematics.

## How results are verified here

- Corpus claims come with the query, corpus version, and counts
- Typological generalizations control for genealogical and areal non-independence
- Historical reconstructions follow the comparative method with explicit sound correspondences
- A model's own intuitions about a language are not data; cite attested examples

## Public data and reference sources

- Universal Dependencies
- WALS, Grambank, Glottolog, PHOIBLE
- Wiktionary dumps, Leipzig Corpora
- CHILDES / TalkBank
- ASJP, Lexibank

Sources are listed from general knowledge as starting points. Confirm current
access terms and versions before use, and record them in the project.

## Seed directions

These are suggestions, not a queue. Any well-posed question in scope is welcome.

- Testing proposed linguistic universals against current typological databases
- Computational phylogenetics of language families with model comparison
- Formal-language results connected to natural-language phenomena
- Documentation aids for low-resource languages built from existing published materials
- Quantitative laws of language (Zipf, Menzerath) examined with proper statistics

## Limits and cautions

- Model fluency is uneven across languages; low-resource claims need attested sources
- Respect community ownership and licences for endangered-language materials
